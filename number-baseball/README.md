# 숫자 야구 구현하기

순수 자바(프레임워크 없음)로 숫자 야구 게임을 구현합니다.
입출력(콘솔, 화면) 없이 **객체와 JUnit 테스트**만으로 요구사항을 검증합니다.

## 진행 규칙

- 패키지: `com.kdt.baseball`
- 단계별로 구현하고, 각 요구사항마다 테스트를 하나 이상 작성합니다.
- 클래스 이름, 메서드 이름, 구조는 자유입니다. 설계 차이를 비교하는 것이 목적입니다.

## 1단계: 숫자 규칙

- 정답과 추측은 모두 **1~9 사이의 서로 다른 숫자 세 개**입니다. 예: `123`, `958`
- 아래 경우는 허용하지 않습니다(`IllegalArgumentException`).
  - 세 자리가 아님: `12`, `1234`, 빈 값
  - 0이 들어 있음: `102`
  - 같은 숫자가 있음: `112`, `121`
  - 숫자가 아닌 글자가 있음: `12a`, `abc`

## 2단계: 판정

- 같은 숫자가 **같은 자리**에 있으면 **스트라이크**입니다.
- 같은 숫자가 **다른 자리**에 있으면 **볼**입니다.
- 결과는 아래 형식의 문장으로 확인할 수 있어야 합니다.

| 정답 | 추측 | 결과 |
|---|---|---|
| 123 | 123 | `3스트라이크` |
| 123 | 124 | `2스트라이크` |
| 123 | 132 | `1스트라이크 2볼` |
| 123 | 234 | `2볼` |
| 123 | 456 | `낫싱` |

- 스트라이크를 먼저, 볼을 나중에 쓰고, 0개인 쪽은 쓰지 않습니다. 둘 다 0개면 `낫싱`입니다.

## 3단계: 게임 진행

- 게임은 정답 하나를 가지고 시작하며, 상태는 **진행 중 / 승리 / 패배** 세 가지입니다.
- 추측할 때마다 시도 횟수가 1 늘어납니다. 규칙에 맞지 않는 추측은 예외가 나고 **시도 횟수에 들어가지 않습니다.**
- 3스트라이크면 **승리**하고 게임이 끝납니다.
- **10번** 안에 맞히지 못하면 **패배**하고 게임이 끝납니다. 10번째에 맞히면 승리입니다.
- 끝난 게임에 추측하면 `IllegalStateException`입니다.

## 4단계: 정답 자동 생성

- 정답을 직접 주지 않으면 규칙에 맞는 정답을 **무작위로** 만듭니다.
- 무작위 정답을 만들어도 1~3단계 테스트는 그대로 할 수 있어야 합니다.
  - 힌트: 테스트에서 "무작위"를 어떻게 정해진 값으로 바꿀 수 있을까요?

## 채점하기

### 왜 연결 클래스가 필요한가요?

클래스 이름과 메서드 이름은 사람마다 다릅니다.
채점 테스트는 **정해진 인터페이스(`NumberBaseballDriver`)만** 부르고,
각자 **`MyNumberBaseballDriver` 한 파일에서 그 호출을 내 코드로 넘겨 줍니다.**

```
채점 테스트 ──▶ NumberBaseballDriver ──▶ MyNumberBaseballDriver ──▶ 내 숫자 야구 코드
 (고정)          (고정, 인터페이스)          (내가 채움)                 (설계 자유)
```

### 메서드별로 할 일

| 메서드 | 할 일 | 돌려줄 값 |
|---|---|---|
| `start(answer)` | 정답을 정해서 새 게임 시작 | 없음 (규칙 위반이면 예외) |
| `guess(number)` | 추측하기 | 판정 문장. 예: `"1스트라이크 2볼"` |
| `attempts()` | 지금까지 시도 횟수 | 정수 |
| `status()` | 게임 상태 | `"PLAYING"`, `"WIN"`, `"LOSE"` |
| `randomAnswer()` | 무작위 정답 하나 만들기 | 세 자리 문자열. 예: `"582"` |

- **연결 클래스에는 로직을 넣지 않습니다.** 판정이나 검증을 여기서 하면 채점은 통과해도 숫자 야구는 구현되지 않은 것입니다.
- 아직 구현하지 않은 단계의 메서드는 `throw`를 그대로 두면 그 단계만 실패로 나옵니다.
- 사용 예시는 [신호등 README](../traffic-light/README.md#채우는-예시)를 참고하세요.

### 실행

IntelliJ에서 `NumberBaseballGradingTest`를 실행하거나:

```bash
./gradlew :number-baseball:test --tests '*GradingTest'
```

## 모여서 이야기할 거리

1. 세 자리 숫자를 `String`, `int`, `List<Integer>` 중 무엇으로 들고 있나요? 아니면 따로 객체를 만들었나요?
2. 검증(1단계)은 어디서 하나요? 정답과 추측이 같은 검증을 공유하나요?
3. 판정 결과를 문장(`String`)으로 바로 만들었나요, 스트라이크와 볼 개수를 가진 객체로 만들었나요?
4. 4단계에서 무작위 값을 테스트하기 위해 무엇을 바꿨나요?
5. 최대 시도 횟수 10을 바꿔야 한다면 어디를 고쳐야 하나요?
